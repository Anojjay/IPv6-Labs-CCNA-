# Lab 1 — IPv6 Dual-Stack Configuration

## Overview

Configured an IPv4/IPv6 dual-stack network using Cisco Packet Tracer.

## Tasks

1. Enable IPv6 unicast routing on R1
2. Configure IPv6 addresses on R1
3. Verify the IPv6 configuration
4. Configure IPv6 addresses and default gateways on the PCs
5. Test IPv4 and IPv6 connectivity between the PCs

## Tools Used

- Cisco Packet Tracer
- Cisco IOS
- IPv4
- IPv6
