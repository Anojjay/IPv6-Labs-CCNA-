# IPv6 Dual-Stack Network Lab

A Cisco Packet Tracer lab focused on configuring and testing IPv6 connectivity.

## Tasks
- Enabled IPv6 unicast routing
- Configured IPv6 addresses on the router
- Configured IPv6 addresses on PCs
- Tested IPv6 connectivity between devices

## Tools
- Cisco Packet Tracer
- Cisco IOS
- IPv6
