# Lab 2 — IPv6 EUI-64 & Static Routing

## Overview

Configured IPv6 addressing and static routing between two Cisco routers using Cisco Packet Tracer.

## Tasks

1. Configure IPv6 addresses on R1 and R2 using EUI-64
2. Configure IPv6 addresses and default gateways on PC1 and PC2
3. Enable IPv6 on the router-to-router interfaces
4. Configure IPv6 static routes to allow PC1 to communicate with PC2

## Tools Used

- Cisco Packet Tracer
- Cisco IOS
- IPv6
- EUI-64
- IPv6 Static Routing
